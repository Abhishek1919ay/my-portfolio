# Abhishek Yadav — Enhanced Olive Portfolio

A clean, responsive developer portfolio built with plain HTML, CSS and JavaScript.

## What's improved
- More polished hero section with developer code card
- Cleaner visual hierarchy and spacing
- Responsive project cards with featured-project treatment
- More professional education cards
- Improved certification cards
- Sticky navigation with active-section highlighting
- Mobile navigation with animated menu icon
- Scroll-reveal animations
- Hover interactions throughout
- Reduced-motion accessibility support
- Consolidated CSS with no framework/build step

## Files
- `index.html`
- `style.css`
- `script.js`

## Before publishing
Replace the `#` links in `index.html` with your real:
- GitHub URL
- LinkedIn URL
- LeetCode URL
- ScrollMotion project URL
- Food Delivery App project URL

Then publish the folder using GitHub Pages, Netlify, Vercel, or another static host.
